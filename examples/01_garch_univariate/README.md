# 01 - GARCH Univariate Models

This module contains tutorials, exercises, and cross-validation scripts for
univariate GARCH-family volatility models implemented in **archbox**:

- GARCH(p,q)
- EGARCH
- GJR-GARCH
- APARCH
- IGARCH
- Component-GARCH (CGARCH)

## Notebooks

| Notebook | Description |
|----------|-------------|
| `notebooks/01_basic_garch.ipynb` | Introduction to GARCH(1,1): estimation, diagnostics, forecasting |
| `notebooks/02_egarch.ipynb` | EGARCH model: leverage effects and log-variance specification |
| `notebooks/03_gjr_garch.ipynb` | GJR-GARCH: asymmetric volatility with threshold term |
| `notebooks/04_aparch.ipynb` | APARCH model: power transformations and asymmetry |
| `notebooks/05_igarch.ipynb` | IGARCH: integrated GARCH for persistent volatility |
| `notebooks/06_cgarch.ipynb` | Component-GARCH: short-run and long-run volatility components |
| `notebooks/07_model_comparison.ipynb` | Comparing all models: information criteria, forecasting, diagnostics |

> Notebooks are created in subsequent phases (F1.2).

## Solutions

Complete solution notebooks with all exercises solved are in `solutions/` (F1.3).

## Datasets

All datasets are synthetic, generated from GARCH(1,1) processes with parameters
calibrated to real-world assets. Seeds are fixed for perfect reproducibility.

| File | Obs | Description | Parameters |
|------|-----|-------------|------------|
| `data/sp500_returns.csv` | 2500 | S&P 500 calibrated returns | omega=1.5e-6, alpha=0.08, beta=0.91, mu=0.0004 |
| `data/ibovespa_returns.csv` | 2500 | Ibovespa calibrated returns | omega=3.0e-6, alpha=0.10, beta=0.88, mu=0.0005 |
| `data/bitcoin_returns.csv` | 2000 | Bitcoin calibrated returns | omega=1.0e-5, alpha=0.15, beta=0.82, mu=0.001 |

**Columns**: `date` (YYYY-MM-DD), `returns` (daily log-returns).

### Regenerating datasets

```bash
cd examples/01_garch_univariate
python utils/generate_datasets.py
```

## Cross-Validation

- **R scripts** (`R/`): Validation against `rugarch` package (F1.4)
- **Stata scripts** (`Stata/`): Validation against Stata's `arch` command (F1.5)

## Requirements

- Python 3.10+
